I've run into the problem of having too many unfinished unity game projects in their separate github repos, so I decided to just create a simple playground project for building various smaller scale projects.

Currently includes: 
- Advanced Rigidbody-based first-person player controller
  - dynamic rigidbody physics (player can be pushed around and reacts to environmental forces)
  - Sprinting
  - Crouching
  - Leaning / Peeking around corners
